# 1.2.0 本地测试版

这是 1.2.0 的本地测试构建，不是正式发布。范围是界面布局、帮助、日志和已确认 bug 修复；不包含适配器契约重构、崩溃安全事务或字体子集化。

## 变化

- 处理页改为全宽响应式布局：900×620 单列；宽屏功能卡两列；内容最大 1440 逻辑像素，不再固定 1180 导致两侧大片空白。
- 新增“帮助”页和每个功能的“说明”按钮；帮助内容离线打包，覆盖功能、模拟、安装/撤销、付费内容和 FAQ。
- 模拟原始输出统一进入左侧“运行日志”；处理页只保留步骤状态，新增“查看运行日志”，失败自动切页。
- 修复：未知支持状态导致模拟继续、撤销读取旧安装状态、外来文件未确认、初始窗口超出屏幕、扫描失败状态、游戏库路径异常、分段控件焦点。
- 版本号、文档和测试同步到 1.2.0。

## 安全边界

本工具不实现付费/订阅/DRM 绕过：

- 不伪造 Steam / DLC / Patreon / SubscribeStar 等购买或订阅状态。
- 不绕过在线校验或付费画廊。
- 不提供通用作弊菜单来解锁付费内容。
- 帮助页会明确说明这一边界；检测到不支持的门禁时不会显示为可用。

## 验证

- `python -m pytest -q`：289 passed、2 skipped、13 subtests passed。
- 900×620、1600×900 浅/深色截图由 `tools/capture_ui_states.py` 生成。
- 构建 provenance、GUI/CLI 冒烟和桌面 exe 哈希在构建后补充。

## 不包含

- 1.2.0 路线图中的适配器契约、崩溃/并发事务、字体子集化。
- 新引擎、通用全图鉴或付费内容解锁。
- 联网授权、遥测或自动更新。
