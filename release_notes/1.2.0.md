# 1.2.0 正式版

本版将现有功能稳定化，渠道为 `stable`。它延续 1.2.0 本地测试版的全宽布局、离线帮助、统一运行日志和四项补丁功能；默认仅字体开启。

## 修复范围

- 撤销前按功能依赖成组检查冲突，避免保留修改过的补丁却删除其依赖字体。
- 撤销写入失败或中断时恢复本次涉及的文件、隔离备份及安装账本。
- 修复游戏库打开处理页不切页、离线书签无法重命名及部分引擎读取异常未转为界面错误。
- 模拟对畸形支持矩阵失败关闭；运行异常后保留结束和清理入口；重复确认主菜单不重置已确认的剧情状态。

## 版本与构建

- GUI、CLI、Windows 版本资源与构建清单统一声明版本和渠道；正式版不设置 prerelease 标志。
- 默认输出 `release/1.2.0/stable/`，单文件 GUI / CLI 位于其 `onefile/` 子目录。旧测试版 exe 保留。
- 构建前要求干净且已提交的 Git 源码，结束时复查 Git 身份与输入；清单包含输入、资源及产物 SHA256。
- 已带较新功能的安装账本由最低可写版本保护；本版拒绝修改 1.3 功能账本，提示使用相应新版撤销。

## 未包含与验证边界

完整适配器契约、跨进程崩溃恢复、字体子集化仍未完成并已延期。本次撤销回滚修复不等于完整 journal / 进程锁实现。实时汉化、帮助检索和快捷启动在 1.3 本地测试渠道开发，不属于本版。

未完整验证的外部 Luna 长流程、完整 NW.js 游戏流程、所有回放场景和未知画廊限制继续保留。最终测试数量、真实引擎结果、exe 冒烟和产物哈希以本次构建旁的验证报告为准；本说明不预填尚未执行的结果。
