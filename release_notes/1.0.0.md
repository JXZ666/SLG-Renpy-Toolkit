从只装字体的单窗口工具，升级为 **1.0.0**：界面重写为五个页面，补丁按功能勾选，字体补丁的支持范围从 Ren'Py 7.6 及以后扩展到 **6–7.5**。

## 改进

- **旧引擎支持（Ren'Py 6–7.5）**：7.6 以前的引擎没有 `config.font_name_map`，之前的字体垫片会让游戏启动即崩。现在预检会读 `renpy/config.py`，看引擎实际声明了哪个钩子，再走对应路线：7.6 及以后照旧用 `config.font_name_map` + `FontGroup`；6–7.5 改用 `config.font_replacement_map`，并在安装时把汉字合并进游戏自己的字体文件。支持范围因此翻了一倍，这是本次最大的变化。
- **五页界面**：窗口重写为 CustomTkinter 的五个可导航页面——处理、游戏库、游戏信息、运行日志、设置，并跟随系统主题。
- **游戏库**：手动添加和切换游戏，记住上次选中的那一款；只保存你手动加的位置，不扫描整块磁盘。
- **偏好保存**：外观（跟随系统 / 浅色 / 深色）和窗口大小会自动记住，重开还在。
- **按功能勾选**：每个功能一张卡片、独立开关，勾谁装谁——汉化预飞（字体）与跳过开场 logo 互不依赖。
- **模拟安装并运行**：把游戏整树复制到临时目录，只在副本上安装所选补丁并启动，原游戏目录一个字节都不动。只有你确认看到了主菜单才记成功；进程正常退出（返回 0）但你未确认时只显示「待确认」，不误报成功。
- **可撤销安装**：撤销不看勾选状态，删掉本工具装过的一切（连同 Ren'Py 编译出的 `.rpyc`），并把安装时隔离的原文件逐字节放回。
- **归档解析加固**：RPA-3.0 索引按不可信输入处理，只接受数据 pickle（显式操作码白名单，不含 `GLOBAL` / `REDUCE`），并对索引大小、操作数、条目数设上限；条目名中的绝对路径、盘符、UNC 与 `..` 一律拒绝，嵌套相对路径（如 `game/script.rpyc`）仍然合法。RPA-1.0/2.0 仍不支持，脚本散放在 `game/` 下则不受影响。
- **下载包**：GUI 用 `SLG-Renpy-Toolkit.exe`（不弹控制台窗口，把游戏文件夹拖到图标上会用该目录预选打开界面），需要命令行时用 `SLG-Renpy-Toolkit-CLI.exe`。这两个 exe 是单文件版，下载后直接双击即可，不需要解压。另附 onedir 压缩包：解压后 exe 必须和同目录的 `_internal` 文件夹放在一起，拷贝或分发时请保留完整文件夹。

## 修复

- **旧引擎启动崩溃**：在 Ren'Py 6–7.5 的游戏上，旧版会无条件写入引擎不认识的 `config.font_name_map`，游戏启动即报 `config.font_name_map is not a known configuration variable`。现在按引擎实际声明的 API 选择路线，不再写错。
- **关闭窗口报错**：关闭窗口时改为销毁 Tk 根窗口，不再调用一个并不存在的父类方法。

## 代码

- **测试闸门补全**：pytest 以前只收集大部分测试文件里的一小半，机制路由断言虽然写好了却从未被执行——断言存在不等于断言被执行。现在默认闸门覆盖 `tests/` 下的全部测试文件，并新增端到端路由回归（真的跑一次安装、读盘断言 shim 用的是哪套 API），且用变异测试验证过它确实能失败。
- **隐私清理**：提交内容里的真实游戏名与个人路径已清除，新增 `tools/check_privacy.py` 在提交前扫描，并覆盖尚未 `git add` 的新文件。
