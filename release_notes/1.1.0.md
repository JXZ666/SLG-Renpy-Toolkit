# 1.1.0

默认安装收敛为字体补丁，入口 / 注入兼容和画廊 / 回放成为可选功能；增加 RPG Maker MV / MZ 字体适配，并把运行异常和发布来源纳入验证。

## 行为变化

- 四项功能：`fontfix` 默认开启；`intro`、`runtime_compat`、`gallery` 默认关闭。保留旧 CLI 参数，新增 `--skip-intro` 主动加入开场跳过；`--features intro` 仍有效。升级不自动撤销旧安装。
- Ren'Py 入口初始化和对白注入兼容按检测机制生成独立补丁，不隐藏游戏异常。
- 标准 Gallery 局部放开图片、条件和前序锁，存档载入后重新应用。专用回放适配按内容指纹匹配，检查资源 / label / 作用域，放开实际 Replay 资格。
- sample A 因原图片画廊占位资源缺失，仅支持回放，明确标为 partial；sample B 隔离诊断发现 2 张标准 Gallery 条目与独立的 59 条自定义场景，其屏幕另有 persistent / seen 门槛，完整适配未验证，保持不支持。当前不提供通用全图鉴承诺，也不批量修改永久存档。
- MV / MZ 首版支持字体回退插件，兼容根目录和 `www/` 布局；其他三项功能明确不支持。插件注册先备份，失败回滚，撤销恢复原 `plugins.js`。
- 模拟会话采集本轮新增 / 变化的 traceback、错误文件和运行异常；主菜单确认与游玩确认独立，正常退出不自动代表成功。
- 单文件 GUI / CLI 和 onedir 产物附构建 provenance：记录输入 / 产物哈希、Git 基准及构建状态，拒绝构建途中输入变化和来源不匹配的 exe。
- 公开源码移除真实游戏缩写与真实 label；文档统一使用 sample A / B / C。`tools/verify_game_copies.py --kind replay` 的原生入口 label 改由调用者通过 `--label` 传入，仓库不再写死。

## 已验证的范围

源码回归包含安装 / 撤销、机制路由、异常状态、画廊资格和发布来源检查，关键测试使用内存变异确认坏逻辑会失败。sample A 的真实 Ren'Py 副本启动探针确认 46 个回放资格、34 个默认变量作用域，并确认资格检查未修改 seen 状态；该探针未播放所有场景。

sample A 副本已复现标准入口缺失，修复后解析到原有入口对象。sample B 副本通过官方 hook 形态的离线注入 mock 复现并修复对白对象 / 文本版本不一致错误，覆盖真实交互、自动推进、slow 分支和开发模式，正常退出；这不等同于真实 Luna 客户端联网游玩验证。

本次复跑源码完整闸门为 136 passed、2 skipped、13 subtests passed；两个跳过项分别是“可选真实引擎测试（本机样本未安装）”和 Windows 符号链接权限。此前配置已审查本地引擎时的记录是 137 passed、1 skipped；本次发布不沿用旧数字，以实际输出为准。画廊模块本次 16 项通过、1 项可选测试跳过。

本次发布提供单文件 GUI / CLI 与 onedir 包，版本资源为 1.1.0.0；构建完成后以 `build_manifest.json` 的 `status=complete`、`source.dirty=false`、输入 / 产物哈希一致为准，并附 `validation_report.json`、`SHA256SUMS.txt`。GUI exe 做隔离启动冒烟，CLI exe 做 `--version` 冒烟。

1.1.0 构建前的真实样本验证记录保留如下：打包后的 CLI 在 sample A / B 副本上分别通过原入口恢复和离线 Luna 对白 / slow 分支验证；sample A 的画廊 exe 安装、真实引擎 46 个回放资格检查和撤销均通过，生成补丁及编译缓存均清除。MV / MZ 最小 API 样例通过 exe 预演、安装、重复安装、加载 / 失败 / 超时 / 插件共存和原配置字节恢复；该结果不代表完整 NW.js / 商业游戏流程通过。本次重建只做隐私标识重命名，未重复完整样本矩阵。

## 保留的限制

完整 NW.js 游戏流程、真实 Luna 客户端全流程、所有回放场景和其他自定义图鉴机制尚未完整实测。未知引擎、归档中的未知锁逻辑和游戏内容指纹变化不会自动获得支持。撤销只恢复工具改动，保留玩家正常游玩取得的已看状态和存档。
