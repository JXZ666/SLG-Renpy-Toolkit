# 1.1.5 界面测试版

这是 1.2.0 UI 工作流的测试构建，不是正式版。功能范围与 1.1.0 相同，主要验证新的界面系统、键盘可访问性和状态反馈。

## 变化

- 统一浅色/深色 token：正文、次要文字、主按钮、输入边界和焦点环达到 WCAG AA 对比度。
- 字体层级统一为 24/16/13/12/11/10；去掉 8/9pt 正文与固定 700/740/760 换行。
- 处理页改为紧凑游戏卡、单列功能行和常驻底部操作栏；模拟步骤改为扁平时间线。
- 新增键盘焦点环、Tab 顺序、Enter/Space 激活、左右方向键切换分段控件，以及 `Ctrl+O` / `F5` / `Ctrl+L` / `Ctrl+Enter`。
- 安装到原游戏、撤销还原、清空日志增加确认；撤销文案明确不回滚存档。
- 模拟确认按钮按状态启用；清理成功隐藏，清理失败提供“重试清理”；`_drain` 异常隔离。
- 后端英文兼容原因映射为中文；未知原因回退到中文提示并在日志保留原文。
- 游戏库改用 `engine_adapters.detect`，MV/MZ 不再误标“路径不可用”；离线条目保留。
- 窗口尺寸按 DPI 缩放保存为逻辑像素，修复 150% 缩放下重启变大。
- 新增 DPI awareness、AppUserModelID 和 13 帧 Windows ICO。

## 验证

- `python -m pytest -q`：256 passed、2 skipped、13 subtests passed。
- 跳过项：可选真实引擎 fixture 不存在；Windows 符号链接权限。不是本次 UI 改动失败。
- 5 页 × 浅/深 × 900×620 截图由 `tools/capture_ui_states.py` 生成；截图不入库。
- 本构建只做桌面端和合成目录验证；真实游戏长流程、屏幕阅读器、高对比度主题仍需单独验收。

## 边界

- 不新增引擎，不改变安装/撤销后端逻辑。
- 不重做信息架构，不替换品牌色，不加入假进度或假功能。
- 界面测试版仍有 Tk/CustomTkinter 的读屏限制。
