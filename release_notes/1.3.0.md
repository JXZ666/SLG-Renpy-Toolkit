# v1.3.0 正式版

Windows x64 单文件版可直接运行。平时使用 `SLG-Renpy-Toolkit.exe`，命令行操作使用 `SLG-Renpy-Toolkit-CLI.exe`。

## 实时汉化

- 游戏库的“检查并汉化”在通过预检后启动本次会话。设置页的“测试连接”使用固定示例检查接口，显示耗时和失败原因。
- 已审核的 Ren’Py 构建覆盖 8.3.0、8.3.6、8.4.1、8.4.2、8.5.0、8.5.2。其中 8.4.2 包含先前审核的 nightly 样本。工具按实际引擎指纹判断，分别显示对白与选项覆盖。
- 有可读源码的常规选项菜单可采用部分静态布局和外观设置。仅编译菜单、带特殊逻辑的菜单、NVL 和未审核构建继续显示原文。
- 默认免费 Google 试验通道，也可自行配置兼容的 AI 接口。默认等待两秒，超时保留原文。运行日志会报告等待游戏文本、授权、网络、限流和格式问题。

## 游戏库与升级

- 其他 Windows 游戏可手动入库、选择启动程序、正常启动或打开本地目录。
- 首次运行正式版会合并旧版和测试版的游戏库及界面设置。重复条目优先使用测试版有效配置，并保留离线书签、启动程序和原配置文件。
- 运行日志集中管理模拟副本。汉化试用仅在字体与汉化预检都通过后启动。帮助页支持离线搜索。
- 本版包含 1.2 的撤销、回滚和界面状态修复。需要移除补丁时，请在工具中选择“撤销还原”。

构建清单、验证报告、SHA256 和组件许可随 Release 提供。RPG Maker MV/MZ 当前支持字体回退，实时汉化将另行适配。
