# 1.3.0 本地测试版

本版在 1.2.0 正式版稳定基线上增加实时游戏内汉化、帮助检索、游戏库快捷操作，并将完整模拟面板移至运行日志。本地测试渠道为 `local-test`，不等于线上正式发布。默认仍只选字体补丁，新增实时汉化需主动选择。

## 实时汉化

- 安装可撤销连接补丁，通过工具“开始汉化”启用本次会话；普通双击游戏显示原文。补丁不含译文、AI Key 或服务凭据。
- 首批审核 Ren'Py 8.3 / 8.4 对白和标准 ADV 选项，预检依据实际接口判断；NVL、自定义菜单和未验证版本保留原文。RPG Maker 暂不支持实时汉化。
- 只翻译当前实际执行的文本，不启动前预译，预测阶段不联网。保留控制 / 格式标签、变量占位符和选项条件、顺序、返回值。
- 默认源语言 `auto`、目标语言 `zh-CN`，等待 2 秒，可调 0–30 秒（0 秒暂停请求并显示原文）；一组菜单共用等待预算。超时或错误保留原文，迟到译文仅缓存，不覆盖当前句。
- 默认使用免费 Google 无 Key 试验通道。端点可能变更、失效或限流；失败会报告原因，不能自动转用收费 AI。
- AI 模式由用户自填接口地址、模型和 Key，费用由所选服务商决定。Key 默认不记忆，主动记忆才用 Windows DPAPI 加密；游戏仅连接带随机会话凭据的本机代理。
- 内置汉化与外部 Luna 内嵌互斥。停止会话或关闭工具后，正常游戏继续运行并回退原文；模拟副本仍需明确结束并清理。

## 帮助、游戏库与日志

- 帮助检索覆盖标题、摘要、章节和正文，支持中文、英文大小写 / 全角归一及多关键词同时匹配；结果有相关摘要并定位章节，支持清空、无结果提示及 `Ctrl+F`。
- 每个游戏首次启动都需手选游戏目录内 exe，即使只找到一个；支持子目录、取消不启动、失效重选及更换启动程序。保存相对路径，拒绝目录外启动器。
- 正常启动以 exe 所在目录为工作目录，关闭工具不结束游戏；“打开文件夹”针对对应库条目，路径失效时明确提示。
- 模拟步骤、结果、主菜单 / 剧情确认、结束及重试清理全部移入运行日志。处理页保留入口，切页或清空文本不影响会话状态。

## 版本共存与验证边界

1.2.0 正式版只稳定原有四项补丁及已确认缺陷。1.3 测试版使用独立界面配置，首次只读导入书签和外观，不覆盖正式版配置。安装账本继续共用，以最低可写工具版本保护新版功能，旧版遇到新账本会提示使用新版撤销。

连接补丁与机翻都属于试验能力，预检通过不能证明全剧情正确。应先在存档隔离副本测试对白、选项、快进、回滚与读档。实际运行报告、GUI / CLI 单文件 exe 的构建来源、资源版本和 SHA256 以最终交付文件为准；不以源码测试替代实际 exe 验证，不预填尚未执行的结果。

免费通道连通、AI 本地兼容服务测试、真实服务质量和真实游戏全流程是不同验收层级。未测试的服务或场景需在最终报告明确保留，不能视为通过。
