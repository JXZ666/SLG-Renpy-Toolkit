# 功能帮助

GUI 左侧“帮助”页是随程序打包的离线说明；功能行右侧的“说明”按钮会直接打开对应主题。帮助内容源码在 `help_content.py`。

## 检索

帮助页可检索标题、摘要、章节标题和正文。中文直接输入；英文不区分大小写，全角英文会归一处理。空白分隔的多个关键词必须同时命中同一主题，例如 `迟到 缓存` 或 `预测 不联网`。

结果优先显示标题和章节命中，并提供相关正文摘要；点击结果定位对应主题或章节。清空查询恢复全部主题，没有匹配时显示无结果提示。`Ctrl+F` 聚焦帮助检索框。

检索完全离线，不读取游戏文件，不向翻译服务发送查询，也不会启动游戏。

## 功能主题

| 主题 | 内容 |
|---|---|
| 汉化预飞（字体） | Ren'Py 字体名分流、旧版字形合并、RPG Maker 字体回退；不翻译文本 |
| 跳过开场 logo | Ren'Py `label_overrides`；可能跳过初始化；先模拟 |
| 游戏入口 / 文本注入兼容 | 入口回退与 Luna 桥接的已验证范围；实验性不等于已验证 |
| 解锁画廊 / 回放 | 已核实标准 Gallery / reviewed replay；不承诺全图鉴，不改存档 |
| 实时汉化（试验） | 已审核 Ren'Py 对白与标准 ADV 选项；当前执行才请求翻译，超时保留原文 |
| 游戏库与快捷启动 | 首次手选 exe、更换启动程序、打开本地文件夹、双版本配置 |
| 模拟与安装 | 隔离副本、主菜单/剧情分别确认、失败清理 |
| 安装与撤销 | 写入前确认、备份、按账本撤销；不回滚存档和自然进度 |
| 付费/订阅内容 | 本工具不伪造购买/订阅状态，不规避付费或 DRM 门禁 |
| 常见问题 | 路径、扫描失败、日志、模拟失败、撤销和不支持的内容 |

## 实时汉化

- 默认免费 Google 无 Key 试验通道，可能变更、限流或失效；失败时回退原文，不自动转用收费 AI。
- AI 模式由用户自填接口地址、模型及 Key。默认不记忆 Key，主动记忆时用 Windows DPAPI 加密；费用由所选服务商决定。
- 默认源语言 `auto`、目标语言 `zh-CN`，等待 2 秒，可调 0–30 秒；一组选项共享预算。迟到译文只缓存，不改写当前句。
- 首批审核 Ren'Py 8.3 / 8.4 对白和标准 ADV 选项，预检逐游戏判断；NVL、自定义菜单和未验证版本保留原文。预测阶段不联网，不启动前批量预译。
- 连接补丁可安装到原游戏并撤销，不含译文或 Key。普通双击显示原文，需从工具“开始汉化”启用会话；停止汉化或关闭工具不会结束正常游戏，只让它回退原文。
- 内置汉化与外部 Luna 内嵌互斥。先在隔离副本试用，验证对白、选项、快进、回滚及读档。

## 游戏库

- 每个游戏首次启动都需手选目录内的 exe，即使只有一个候选。支持子目录，取消不启动，启动路径失效后重新选择；“更换启动程序”可主动改选。
- 保存相对游戏根目录的路径，不接受目录外启动器。“开始游戏”的工作目录是 exe 所在目录，关闭工具不结束正常游戏。
- “打开文件夹”打开该库条目的目录；路径失效时提示，不依赖处理页当前游戏。
- 1.3 测试版界面配置独立，首次只读导入正式版书签和外观；安装账本共用，通过最低可写工具版本保护新版功能。

## 日志与模拟

- 安装、撤销、扫描和模拟的原始输出都进入左侧“运行日志”。
- 完整模拟操作区位于“运行日志”：步骤、结果、主菜单与剧情确认、结束、重试清理均在这里。
- 处理页的模拟入口会跳转到日志页；切页或清空日志文本不会清除模拟会话状态。
- 日志支持复制、导出和清空；清空前会确认。

## 内容边界

“付费/订阅内容”说明不是功能承诺：

- 不实现 Steam / itch / Patreon / SubscribeStar 等授权伪造。
- 不绕过在线校验、DLC 加密或付费画廊。
- 不提供通用作弊菜单来解锁付费内容。
- 如果游戏本身需要购买或订阅，请通过官方渠道购买/恢复。

工具能做的是说明当前支持范围、拒绝不安全的补丁，并保证安装/撤销可审计。

## 维护

- 新增功能时，在 `features.CATALOG` 加条目，并在 `help_content.TOPICS` 增加同名主题。
- `tests/test_help_content.py` 会检查每个功能都有帮助主题和必需小节。
- `help_content.search(query)` 返回每个命中主题一条结果：`topic_id`、`title`、`section_index`、`heading`、`snippet`；无章节定位时 `section_index` 为 `None`。
- `tests/test_help_search.py` 覆盖归一、多词同时匹配、正文命中、排序、清空、无结果、定位和返回值独立性。
- 帮助页不联网、不读取游戏目录；截图和测试只用合成文本。
