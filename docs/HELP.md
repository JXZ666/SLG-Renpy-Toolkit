# 功能帮助

GUI 左侧“帮助”页是随程序打包的离线说明；功能行右侧的“说明”按钮会直接打开对应主题。帮助内容源码在 `help_content.py`，本节只做导航。

## 功能主题

| 主题 | 内容 |
|---|---|
| 汉化预飞（字体） | Ren'Py 字体名分流、旧版字形合并、RPG Maker 字体回退；不翻译文本 |
| 跳过开场 logo | Ren'Py `label_overrides`；可能跳过初始化；先模拟 |
| 游戏入口 / 文本注入兼容 | 入口回退与 Luna 桥接的已验证范围；实验性不等于已验证 |
| 解锁画廊 / 回放 | 已核实标准 Gallery / reviewed replay；不承诺全图鉴，不改存档 |
| 模拟与安装 | 隔离副本、主菜单/剧情分别确认、失败清理 |
| 安装与撤销 | 写入前确认、备份、按账本撤销；不回滚存档和自然进度 |
| 付费/订阅内容 | 本工具不伪造购买/订阅状态，不规避付费或 DRM 门禁 |
| 常见问题 | 路径、扫描失败、日志、模拟失败、撤销和不支持的内容 |

## 日志

- 安装、撤销、扫描和模拟的原始输出都进入左侧“运行日志”。
- 处理页的“模拟步骤”只表示阶段状态，不是完整日志。
- 模拟卡有“查看运行日志”；模拟失败会自动切到日志页。
- 日志支持复制、导出和清空；清空前会确认。

## 内容边界

“付费/订阅内容”说明不是功能承诺：

- 不实现 Steam / itch / Patreon / SubscribeStar 等授权伪造。
- 不绕过在线校验、DLC 加密或付费画廊。
- 不提供通用作弊菜单来解锁付费内容。
- 如果游戏本身需要购买或订阅，请通过官方渠道购买/恢复。

工具能做的是说明当前支持范围、拒绝不安全的补丁，并保证安装/撤销可审计。

## 维护

- 新增功能时，在 `features.CATALOG` 加条目，并在 `help_content.TOPICS` 增加同名主题。
- `tests/test_help_content.py` 会检查每个功能都有帮助主题和必需小节。
- 帮助页不联网、不读取游戏目录；截图和测试只用合成文本。
