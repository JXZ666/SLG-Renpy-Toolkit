# UI 系统：SLG-Renpy-Toolkit

本文件是界面规则，不是营销文案。颜色、字号、间距、圆角的唯一代码来源是 `ui_tokens.py`；`appgui.py` 不应再出现原始 `#rrggbb`。

对比度：

- 正文/次要文字 ≥ 4.5:1。
- 主按钮白字 / `accent_fill` = 5.56:1。
- 浅色 `accent_text` / `accent_soft` = 5.71:1；深色 6.16:1。
- 浅色 `border_strong` / panel = 3.08:1；深色 3.65:1。不要把它用在 `bg` 上（浅色对 `bg` 只有 2.83:1）。
- 焦点环对背景 ≥ 3:1。

## 2. 字体

| 角色 | 字号 | 用途 |
|---|---:|---|
| `page` | 24 bold | 页面标题 |
| `section` | 16 bold | 区块标题 |
| `card_title` | 13 bold | 卡片标题 |
| `body` | 12 | 正文 |
| `secondary` | 11 | 说明、按钮 |
| `meta` | 10 | 路径、chip、版本、辅助信息 |
| `mono` | 11 | 运行日志 |

规则：

- 不再使用 8/9pt 作为正文或说明。
- 中文使用 Microsoft YaHei UI；日志使用 Consolas，允许系统回退。
- 标签 `wraplength` 由实际宽度动态计算，不写死 700/740/760。
- 长路径可换行；不强制截断，避免用户看不到真实位置。

## 3. 间距、形状与宽度

- 间距：4 / 8 / 12 / 16 / 24 / 32。
- 圆角：控件 6、按钮 10、卡片 14。
- 卡片只用于表达层级；不在卡片里再套带边框的卡片。
- 主操作区是常驻底栏，不随滚动消失。
- 内容最大宽度 1440 逻辑像素；900×620 单列，宽度 ≥1120 时功能卡和帮助卡两列。
- 高 DPI 下窗口尺寸按逻辑像素保存，并按当前屏幕高度钳制最小窗口。

## 4. 焦点与键盘

- 每个可操作控件必须有 `takefocus=1` 的内部目标。
- 焦点环：按钮/复选框 2px canvas 高亮；输入框/文本框 2px 边框，颜色 `focus`。
- `Tab` 顺序：侧栏导航 → 游戏路径/浏览 → 功能复选框 → 模拟/安装/撤销 → 页面其他操作。
- `Enter` / `Space` 激活按钮和复选框；分段控件用左右方向键。
- 快捷键：`Ctrl+O` 选择目录、`F5` 重新检查、`Ctrl+L` 打开日志、`Ctrl+Enter` 模拟运行、`Esc` 退出焦点。
- 焦点不能只靠颜色变化；必须同时有可见轮廓。

## 5. 确认、状态与反馈

- 安装到原游戏：确认，列出功能、路径、备份/撤销说明。
- 撤销：确认，列出将撤销的功能，明确“不回滚存档和自然进度”。
- 清空日志：确认，提示先导出。
- 未知支持：不勾选、禁用，并显示“未确认”；不能冒充“已支持”。
- 实验性支持：显示“实验性”，保留可测试入口，不写成“已验证”。
- 不支持：显示“当前游戏不支持此功能：…”，并给出中文原因。
- 空状态：日志显示“暂无日志”和如何产生日志；游戏库显示添加入口说明。
- 错误：就地状态 + 日志；弹窗说明可恢复动作，不只有“出错了”。
- 模拟确认按钮只在进程启动后启用；清理后隐藏；清理失败显示“重试清理”。

## 6. 文案

- 优先中文；技术标识可放在中文括号内，例如 `config.font_name_map`、`FontGroup.add`。
- 未知英文原因不直接显示；固定中文回退，原文写入日志。
- 不使用 `——` 装饰；用句号、分号或项目符号。
- 不承诺未验证的效果；区分“可用”“实验性”“不支持”“未确认”。
- 不写营销话术，不使用假进度、假截图、假成功。
