# UI 审计：1.2.0 本地测试版

审计对象：`appgui.py` 的六页桌面界面（处理、游戏库、游戏信息、运行日志、帮助、设置），以及 `app_state.py` 的窗口状态持久化。审计基于 Windows 11、Python 3.13.12、CustomTkinter 6.0.0、系统缩放 150%。

## 1. 设计阅读

这是面向中文玩家和汉化工作者的 Windows 桌面工具，不是落地页、作品集或数据看板。

- `DESIGN_VARIANCE: 3`：保持规整的单列工具界面，不做不对称营销页。
- `MOTION_INTENSITY: 2`：只保留主题切换、进度条和焦点反馈，不做入场动画。
- `VISUAL_DENSITY: 5`：工具密度，但主操作必须常驻可见。
- 保留现有紫色品牌，不换成 skill 推荐的海军蓝/绿色，也不引入 Web 字体。

`design-taste-frontend` 只采用其可迁移规则：品牌优先、形状一致、CTA 对比度、状态完整、copy 自审；不套用 hero、section、图片、SEO、GSAP 等落地页规则。`ui-ux-pro-max` 采用 Minimalism/Swiss 方向与可访问性规则；拒绝它返回的 landing page 结构和 Web 字体。

## 2. 审计前的问题

### 2.1 对比度

| 组合 | 审计前 | 问题 |
|---|---:|---|
| 浅色次要文字 `#777a92` / 白底 | 4.21:1 | 低于 4.5 |
| 浅色次要文字 / 浅底 | 3.87:1 | 低于 4.5 |
| 浅色选中导航 / 淡紫底 | 4.23:1 | 低于 4.5 |
| 浅色主按钮文字 / 紫底 | 3.88:1 | 低于 4.5 |
| 浅色输入框边界 / 白底 | 1.26:1 | 控件边界不可辨 |
| 深色主按钮文字 / 紫底 | 2.28:1 | 严重不足 |
| 深色选中分段文字 / 紫底 | 2.28:1 | 严重不足 |
| 深色输入框边界 / 面板 | 1.37:1 | 控件边界过弱 |

### 2.2 排版与密度

- 字体档位 8/9/10/11/12/13/14/21，正文和元信息大量使用 9/10，8pt 用于路径与 chip。
- 圆角 7/8/9/10/11/12/13/14 混用；间距 3/4/6/7/8/9/11/12/13/15/18/20/22/24 无节奏。
- 4 个功能卡为 2×2 等宽大卡，模拟区又嵌在“执行”卡内，形成卡片套卡片。
- 工具逻辑 900×620 下，主操作在滚动区下方；首屏看不到安装/撤销。

### 2.3 键盘与焦点

- `tk_focusNext` 链只覆盖 `CTkEntry` 内部 entry；`CTkButton`/`CTkCheckBox` 的 canvas 没有 `takefocus`。
- 没有 `<FocusIn>/<FocusOut>` 样式，键盘用户看不到焦点。
- 没有 `Ctrl+O`、`F5`、`Ctrl+L` 等桌面工具常用快捷键。

### 2.4 状态与确认

- “开始处理”直接写原游戏，没有二次确认；“撤销还原”也没有确认。
- 未安装补丁时撤销仍会执行，并显示成功文案。
- 模拟确认按钮在进程启动前就可点击；清理后仍显示但无操作。
- `exit 0` 未确认时缺少“结束模拟并清理”的明确出口。
- 清理失败只能关窗，没有重试。
- `_drain` 中单个事件处理器异常会让界面永久停在“正在处理”。
- 未知支持状态被当成可用；英文 reason 直出。
- 游戏库用 `<path>/game` 判断，MV/MZ 被误标“路径不可用”；离线条目在保存时被丢弃。
- 日志空时只有空白，没有空状态。

### 2.5 内容与 IA

- “游戏信息”实际是兼容性/安装诊断；副标题不准确。
- `——` 前缀与长 `·` 串混用，长英文 reason 直接进入界面。
- 功能描述偏技术，首屏缺少一句可读摘要。
- 错误弹窗只有“出错了，看下面的日志”，没有恢复动作。

### 2.6 DPI 与图标

- 没有显式 DPI awareness / AppUserModelID。
- ICO 只有 16/24/32/48/64/128/256，缺少 20/30/36/40/44/96。
- 窗口尺寸保存的是物理像素，150% 缩放下会每次重启放大 1.5 倍。

## 3. 本次改动

- 新增 `ui_tokens.py`，统一浅/深色、字体角色、间距、圆角；`audit()` 对 10 组关键组合做 WCAG 断言。
- 新增 `ui_text.py`，把后端英文 reason 映射为中文；未知原因回退到中文提示，原文写入日志。
- 新增 `ui_focus.py`，为按钮、复选框、输入框、文本框、分段控件建立 Tab 焦点、可见焦点环和 Enter/Space 激活。
- 处理页改为：紧凑游戏卡、单列功能行、常驻底部操作栏、扁平模拟时间线。
- 游戏库改用 `engine_adapters.detect`；离线条目保留并显示“路径不可用”；路径动态换行。
- 运行日志增加空状态、空文本禁用复制/导出、清空确认。
- 安装/撤销/清空日志增加确认；撤销文案改为中性且说明不回滚存档。
- 模拟确认按钮按状态启用；清理成功隐藏，清理失败提供“重试清理”。
- `_drain` 隔离事件处理器异常。
- 窗口尺寸按 DPI 缩放换算为逻辑像素保存。
- 新增 13 帧 ICO、DPI awareness、AppUserModelID。

## 4. 验证结果

- 对比度：浅/深两套全部达到正文 4.5:1、控件边界/焦点 3:1；详见 `docs/UI_SYSTEM.md`。
- 900×620：底部操作栏常驻可见；页面内容可滚动；动态 wrap 不再出现一字一行。
- 键盘：处理页 Tab 链可从浏览按钮到功能复选框、模拟、安装、撤销；焦点环显示在按钮/输入框上。
- 现有测试基线保持通过；新增 UI token、文案、焦点/确认、布局、Windows 平台测试。

## 5. 已知边界

- Tk/CustomTkinter 对 Windows UI Automation / 屏幕阅读器的支持有限；本次保证键盘、焦点、文本标签和对比度，不承诺完整读屏。
- Windows 高对比度主题未做专门适配；浅/深色主题按 WCAG 对比度校验。
- 200% 缩放下控件仍可用，但未把所有页面逐像素截图纳入自动门禁；100%/125%/150%/200% 做人工冒烟。
- 未验证真实游戏的长路径、异常字体、超大日志等所有组合；测试使用合成目录。
- 1.2.0 新增帮助页；不重做品牌、不加入假进度或假功能。
- 不实现付费/订阅/DRM 绕过；未知或付费门禁保持不支持。
